Project Overview

I am currently developing and upgrading a custom fork of the Xash3D-FWGS engine, taking it in a brand-new direction. The primary goal of this project is to breathe new life into the classic Counter-Strike 1.6 foundation and deliver a modernized, next-level gameplay experience.

Key Features Currently in Development:

Graphics & Rendering: Added full support for a 64-bit Vulkan renderer for improved performance and modern hardware compatibility.

Engine & Core Systems:

Expanded Server Capacity: Upgraded core game logic to unlock the player limit from 32 to 64 players.

Visceral Combat & Gore: Implemented a completely overhauled Blood & Gore system, paired with a dynamic Dismemberment system.

Modernized Gunplay: Built a custom Gunfight system that delivers punchy, visceral shooting feedback and weapon handling heavily inspired by Call of Duty: Modern Warfare (2019).

Movement Mechanics: Integrated fluid Sprint and Tactical Sprint mechanics, bringing the fast-paced, tactical mobility of Modern Warfare (2019) into the classic GoldSrc/Xash3D environment.
